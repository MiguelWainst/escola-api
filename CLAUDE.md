## Regra absoluta

Trabalhe de forma autônoma sem pedir confirmação para ações normais de desenvolvimento.

Pode:
- criar arquivos do frontend;
- editar arquivos do frontend;
- instalar dependências do frontend;
- executar npm;
- executar TypeScript;
- executar lint;
- executar build;
- executar testes;
- executar comandos git somente para inspeção.

Não pode:
- modificar qualquer arquivo do backend;
- alterar Java/Spring Boot;
- alterar DTOs;
- alterar Controllers;
- alterar Security;
- alterar banco;
- alterar pom.xml;
- alterar configurações do backend.

Se uma funcionalidade exigir alteração no backend, não faça a alteração. Continue com o restante possível e registre a limitação.
